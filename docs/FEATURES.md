# 产品功能索引

本文件记录需要保留的产品行为，不是开发流程或易变发布状态的事实源。具体游戏与架构行为以 `DESIGN.md`、`SIM.md`、`META.md` 和测试为准。

- Windows 与 Android 共用主界面、登录流程、协议和数据模块；平台专属能力应正常降级。
- Windows 提供桌面全屏、原生 TCP、文件选择和原生更新能力。
- Android 不显示桌面专属控件，触控布局适配常见横屏和短高度横屏。
- 主界面、弹窗、抽屉和设置页在支持的桌面与移动尺寸下不得重叠、裁切或溢出视口。
- 账户与回放功能已移除此前实现的增强版本：`hello` 不再携带 `profileTag`，服务端不再启动身份、对局记录或回放接口与独立端口，客户端没有 `#tag` 输入、同名档案选择和对局记录入口。遗留的 `var/replays.sqlite` 与已有录像文件保持原样并被忽略（不读取、不写入、不删除）。
- 客户端在本机复用玩家资料：玩家代号、上次与自命名的配队、干员调配（技能、精锐模组、潜能与练度）保存在 `localStorage` 的 `sp.pref.profile`（带 `schemaVersion`），下次启动客户端或进入配队流程时恢复上一次的有效配置；档位不清空。
- 本机资料不含认证凭据、四位 tag、服务端身份、对局结果或回放数据。数据缺失、版本不符、损坏、字段非法、干员不存在或超出当前模式容量时，按默认值或过滤后的合法子集安全降级，客户端不会因此启动失败，也不会向服务端提交非法配队；服务端仍按当前可用干员与模式规则重新校验。
- 共享前端、协议或数据变化必须同时验证 Windows 和 Android。
