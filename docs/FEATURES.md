# 产品功能索引

本文件记录需要保留的产品行为，不是开发流程或易变发布状态的事实源。具体游戏与架构行为以 `DESIGN.md`、`SIM.md`、`META.md` 和测试为准。

- Windows 与 Android 共用主界面、登录流程、协议和数据模块；平台专属能力应正常降级。
- Windows 提供桌面全屏、原生 TCP、文件选择和原生更新能力。
- Android 不显示桌面专属控件，触控布局适配常见横屏和短高度横屏。
- 主界面、弹窗、抽屉和设置页在支持的桌面与移动尺寸下不得重叠、裁切或溢出视口。
- 账户保持稳定 `userId` 和同名不同 tag 隔离；回放保持旧记录可读，并使用独立可配置的 TCP-only 端口。
- 共享前端、协议或数据变化必须同时验证 Windows 和 Android。
