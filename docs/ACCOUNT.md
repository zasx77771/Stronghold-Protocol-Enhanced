# 账户与身份规则

账户系统独立于回放功能。回放只引用本文件定义的稳定身份，不重新定义账户。

- 数据库使用不可见且不可变的 `userId` 作为关联主键。
- 用户可见身份由昵称和四位数字 `tag` 组成；tag 范围为 `0000` 至 `9999`，不占用昵称长度。
- 输入 `昵称#tag` 时只绑定完全匹配的已有档案；不匹配时提示错误，不自动新建。
- 仅输入昵称且不存在同名档案时创建档案并分配未占用 tag；存在同名档案时列出 tag，允许绑定或明确新建。
- 同名不同 tag 的档案、统计和对局索引必须隔离。每局保存当时的昵称和 tag 快照，后续改名不改写历史。
- 客户端可保存本地档案令牌；恢复令牌、账户数据库和个人数据不得提交 Git 或进入公开产物。
- 数据迁移前备份，使用事务，失败时完整回滚。
- 四位 tag 只用于个人服务中的区分与找回，不是密码或公网认证凭证。
