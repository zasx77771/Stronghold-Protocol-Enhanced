# 对局记录与回放规则

账户和身份由 `docs/ACCOUNT.md` 定义。本文件只规定记录、录像、查询和播放边界。

- 每局录像只保存一份，通过参与关系关联多个 `userId`；同名不同 tag 的查询按 `userId` 隔离。
- 记录至少包含种子、模式、地图、数据版本、玩家与座位、阵容、装备、结算、成功操作、系统事件和必要关键帧。
- AI、超时、断线托管、暂停和退出等影响结果的系统事件必须进入记录。
- 录像默认永久保留；数量、空间、天数和自动清理策略可配置，未启用清理时只能由用户明确删除。
- 支持导出、导入、重复识别、完整性校验和损坏提示。播放、导入和迁移不得改写原始录像。
- 跨版本至少保证结算和关键帧可读；只有规则与内容兼容时才要求精确重新模拟。
- 回放服务使用独立、可配置的 TCP-only 端口，不与网页 HTTP、WebSocket 或游戏 TCP 共用。
- `3002` 只是当前默认值，不是长期协议约束；客户端不得硬编码端口。
- 回放端口只接受长度前缀 JSON TCP 协议，不得提供网页、HTTP API 或重定向。
- 数据库升级前备份，使用事务，失败时完整回滚；录像、账户关联、备份和恢复信息不得提交 Git 或进入公开产物。
